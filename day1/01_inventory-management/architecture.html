Filter System

The application implements 4 global filters that apply across multiple views:

  • Time Period: Months (2025-01, 2025-02) and Quarters (Q1-2025, Q2-2025)
  • Warehouse: Filter by warehouse location
  • Category: Filter by product category
  • Order Status: Filter by order status (pending, completed, etc.)

Key Business Metrics

  • Total Revenue: Sum of all order totals
  • Total Stock Value: Sum of inventory stock values
  • Pending Orders: Orders awaiting completion
  • Monthly Revenue Goals: $800K per month single, $9.6M YTD
  • Demand Forecasts: Projected vs. actual demand
  • Backlog: Unfulfilled orders awaiting stock

Development Workflow

Quick Start

The system runs two separate development servers that communicate via HTTP:

Backend: cd server && uv run python main.py
Frontend: cd client && npm run dev
API Docs: http://localhost:8001/docs

Key Patterns

  • Vue 3 Composition API: All components use modern composition API pattern
  • Centralized API Client: Axios calls managed in api.js
  • Filter Propagation: Global filters via query parameters
  • Pydantic Validation: All API responses validated server-side
  • Mock Data: JSON files loaded at server startup
  • Type Safety: Response models ensure consistency
